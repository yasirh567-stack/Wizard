# Wizard

An AI-powered personal finance copilot, plus the AI Product Manager agent
that runs product management *on it* — using the app's own telemetry,
synthetic support tickets, and experiment results to propose, test, and
evaluate what to build next.

Working name — open to renaming once there's a build to name.

## Status

Phase 1 (backend skeleton) in progress — see `docs/SPRINT_1.md`. Planning
docs in `docs/` (problem, research, personas, requirements, architecture,
roadmap) were written before any app code, same discipline as this author's
other projects. See `backend/README.md` to run it.
